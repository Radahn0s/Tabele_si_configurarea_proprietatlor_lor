📋 Subiect 1: Inserare și formatare tabele

Cum creezi și formatezi tabele în Word

📚 Noțiuni teoretice:

Tabelul în Word este o structură organizată în rânduri și coloane care permite prezentarea clară a datelor. Fiecare intersecție rând-coloană formează o celulă.

Elementele unui tabel: Row (rând) - linie orizontală cu celule. Column (coloană) - linie verticală cu celule. Cell (celulă) - intersecția rând-coloană unde introduci text/date. Header Row - primul rând, de obicei cu titlurile coloanelor.

💡 Mod rapid: Tastează textul cu TAB între coloane și ENTER între rânduri, apoi selectează tot și apasă Table → Convert Text to Table.

Pași pentru crearea tabelelor:

  1. Inserare clasică:
    • Insert → Table → Insert Table
    • Specifică numărul de coloane și rânduri
    • AutoFit behavior: Fixed column width / AutoFit to contents / AutoFit to window
  2. Inserare rapidă (grid):
    • Insert → Table → Glisează mouse-ul peste grilă
    • Maximum 10x8 tabele din grid
  3. Desenare tabel:
    • Insert → Table → Draw Table
    • Desenează conturul, apoi liniile interioare
    • Util pentru tabele neuniforme
  4. Formatare de bază:
    • Selectează tabel → Layout → Properties
    • Table: setează lățimea totală, alignment (Left/Center/Right)
    • Row: setează înălțimea rândurilor
    • Column: setează lățimea coloanelor
    • Cell: setează dimensiuni și aliniament în celulă

🎨 Subiect 2: Stiluri și modificări avansate

Personalizarea aspectului tabelelor

📚 Noțiuni teoretice:

Table Styles sunt seturi predefinite de formatare (culori, fonturi, borduri) care dau un aspect profesional tabelului rapid.

Shading = umplerea celulelor cu culoare. Borders = liniile care delimitează celulele. Poți personaliza grosimea, stilul (solid, dashed, double) și culoarea.

Pași pentru stilizare:

  1. Aplicare stil predefinit:
    • Click în tabel → Design (Table Design)
    • Alege din Table Styles gallery
    • Bifează opțiuni: Header Row, Total Row, Banded Rows, First Column, Last Column
  2. Modificare culori celule (Shading):
    • Selectează celule → Design → Shading
    • Alege culoare sau More Colors pentru personalizare
  3. Modificare borduri:
    • Selectează celule → Design → Borders
    • Opțiuni: All Borders, Outside Borders, Inside Borders, No Border
    • Borders and Shading (dialog) pentru control complet: stiluri linie, grosime, culoare
  4. Aliniament text în celule:
    • Layout → Alignment (9 opțiuni: top-left, center, bottom-right, etc.)
    • Text Direction pentru rotire text

🔧 Subiect 3: Operații cu celule și sortare

Modificări structurale ale tabelului

📚 Noțiuni teoretice:

Merge Cells = unirea mai multor celule într-una singură. Split Cells = împărțirea unei celule în mai multe celule. Sort = aranjarea rândurilor după criteriul dintr-o coloană (alfabetic, numeric, ascendent/descendent).

Operații cu tabele:

  1. Adăugare rânduri/coloane:
    • Click în celulă → Layout → Insert Above/Below (rânduri)
    • Layout → Insert Left/Right (coloane)
    • Shortcut: Click dreapta → Insert
  2. Ștergere rânduri/coloane:
    • Selectează rând/coloană → Layout → Delete → Delete Rows/Columns
    • Delete Table pentru a șterge tot tabelul
  3. Unire celule (Merge):
    • Selectează celulele → Layout → Merge Cells
    • Folosit pentru titluri sau celule comune
  4. Împărțire celule (Split):
    • Click în celulă → Layout → Split Cells
    • Specifică numărul de coloane și rânduri
  5. Sortare date:
    • Click în coloana după care sortezi → Layout → Sort
    • Alege Sort by (coloană), Type (Text/Number/Date), Ascending/Descending
    • Bifează "Header row" dacă primul rând e titlu

📐 Subiect 4: Formule și calcule în tabele

Calcule matematice simple în Word

📚 Noțiuni teoretice:

Word permite calcule de bază în tabele folosind formule. Sintaxa este similară cu Excel: =FUNCȚIE(referințe)

Funcții disponibile: SUM (sumă), AVERAGE (medie), MAX (valoare maximă), MIN (valoare minimă), COUNT (numără celule cu numere), PRODUCT (produs).

Referințe celule: ABOVE (toate celulele deasupra), BELOW (toate sub), LEFT (la stânga), RIGHT (la dreapta), sau celule individuale (A1, B2, etc.).

Lucrul cu formule:

  1. Inserare formulă:
    • Click în celula unde vrei rezultatul
    • Layout → Formula (Data group)
    • Se sugerează automat formula (de ex. =SUM(ABOVE))
  2. Exemple formule comune:
    • =SUM(ABOVE) - sumează toate valorile deasupra
    • =AVERAGE(LEFT) - media valorilor din stânga
    • =MAX(A1:A5) - valoarea maximă din celulele A1 la A5
    • =B2*C2 - înmulțește valorile din B2 și C2
  3. Actualizare formule:
    • Formulele NU se actualizează automat când schimbi datele
    • Click dreapta pe rezultat → Update Field (F9)
    • Sau selectează tot tabelul → F9
  4. Number Format:
    • În dialogul Formula, setează formatul: #,##0.00 (pentru 2 zecimale)
    • 0% pentru procente

🖼️ Subiect 5: Conversii și tabele complexe

Transformări și funcționalități avansate

📚 Noțiuni teoretice:

Text to Table = conversia textului obișnuit (delimitat cu TAB, virgulă, spațiu) în tabel structurat. Table to Text = operația inversă.

Nested Table = tabel inserat în interiorul unei celule din alt tabel - util pentru layouts complexe.

Repeat Header Rows = funcție care repetă automat rândul antet pe fiecare pagină când tabelul se întinde pe mai multe pagini.

Operații avansate:

  1. Conversie Text → Tabel:
    • Scrie text cu delimitatori (TAB între coloane, ENTER între rânduri)
    • Selectează textul → Insert → Table → Convert Text to Table
    • Alege delimitatorul: Tabs, Commas, Other
  2. Conversie Tabel → Text:
    • Selectează tabelul → Layout → Convert to Text
    • Alege separator: Tabs, Commas, Paragraph marks
  3. Tabele imbricate (Nested):
    • Click în celula unde vrei sub-tabelul
    • Insert → Table → Inserează tabel normal
    • Util pentru layouts cu secțiuni complexe
  4. Repetare antet pe pagini multiple:
    • Selectează rândul/rândurile antet
    • Layout → Repeat Header Rows
    • Antetul apare automat pe fiecare pagină
  5. Split Table (împărțire tabel):
    • Click în rândul unde vrei să împarți
    • Layout → Split Table
    • Tabelul se divide în două tabele separate

📈 Subiect 6: SmartArt și diagrame

Grafice conceptuale și organigramе

📚 Noțiuni teoretice:

SmartArt este o funcție Word pentru crearea rapidă de diagrame vizuale profesionale: organigramе, procese, cicluri, ierarhii, relații.

Categorii SmartArt: List (liste vizuale), Process (flux de procese), Cycle (cicluri repetitive), Hierarchy (organigramе), Relationship (relații între concepte), Matrix (matrici 2x2), Pyramid (piramide).

Lucrul cu SmartArt:

  1. Inserare SmartArt:
    • Insert → SmartArt
    • Alege categoria (List, Process, Cycle, Hierarchy, etc.)
    • Selectează diagrama dorită → OK
  2. Adăugare text:
    • Metoda 1: Click direct în formă și tastează
    • Metoda 2: Text Pane (buton stânga diagramei) - listă cu bullet points
    • TAB/Shift+TAB pentru indentare în Text Pane
  3. Adăugare/ștergere forme:
    • Selectează formă → Design → Add Shape (Before/After/Above/Below)
    • Delete pentru ștergere
    • Add Bullet pentru sub-puncte (în liste)
  4. Schimbare layout SmartArt:
    • Selectează SmartArt → Design → Layouts
    • Alege alt layout din aceeași categorie sau altă categorie
    • Textul rămâne, doar aspectul se schimbă
  5. Formatare și culori:
    • Design → Change Colors (scheme de culori predefinite)
    • Design → SmartArt Styles (stiluri 2D/3D)
    • Format → Shape Fill/Outline pentru personalizare individuală

📊 Subiect 7: Forme geometrice și Drawing Tools

Desenare și editare forme în Word

📚 Noțiuni teoretice:

Shapes sunt obiecte grafice (dreptunghiuri, cercuri, săgeți, stele, etc.) pe care le poți insera și formata în Word pentru diagrame personalizate.

Drawing Canvas = zonă delimitată unde poți desena mai multe forme care rămân grupate. Text Box = formă specială pentru adăugare text independent de corpul documentului.

Lucrul cu forme:

  1. Inserare formă:
    • Insert → Shapes → Alege forma
    • Click și drag în document pentru a desena
    • Categorii: Lines, Rectangles, Basic Shapes, Block Arrows, Flowchart, Stars and Banners, Callouts
  2. Adăugare text în forme:
    • Click dreapta pe formă → Add Text
    • Sau click direct în formă și tastează
    • Format text ca în Word normal (font, size, bold, etc.)
  3. Formatare forme:
    • Shape Fill - culoarea interiorului
    • Shape Outline - culoarea și grosimea conturului
    • Shape Effects - umbre, reflexii, glow, 3D
    • Format → Format Pane pentru control detaliat
  4. Aranjare forme:
    • Format → Align (Left, Center, Right, Top, Middle, Bottom)
    • Distribute Horizontally/Vertically pentru spațiere egală
    • Bring Forward / Send Backward pentru layering
  5. Grupare forme:
    • Selectează mai multe forme (Ctrl+Click)
    • Format → Group → Group
    • Formele grupate se mișcă/formatează împreună
    • Ungroup pentru separare
  6. Conectori (pentru flowcharts):
    • Insert → Shapes → Lines → Connectors
    • Conectează forme - rămân atașate când muți formele
    • Elbow, Straight, Curved connectors

🎯 Subiect 8: Diagrame Excel integrate

Integrarea diagramelor Excel în Word

📚 Noțiuni teoretice:

Word permite inserarea de diagrame Excel care păstrează legătura cu datele - când modifici datele, diagrama se actualizează automat.

Diferențe față de SmartArt: SmartArt = diagrame conceptuale (organigrame, procese). Excel Charts = grafice cu date numerice (bare, linii, pizza).

Inserare și editare diagrame Excel:

  1. Inserare diagramă nouă:
    • Insert → Chart
    • Alege tipul (Column, Line, Pie, Bar, Area, XY, etc.)
    • Se deschide mini-Excel cu date sample
    • Înlocuiește datele cu ale tale
  2. Editare date:
    • Click pe diagramă → Design → Edit Data
    • Se redeschide fereastra Excel
    • Modifică valorile → diagrama se actualizează instant
  3. Schimbare tip diagramă:
    • Click pe diagramă → Design → Change Chart Type
    • Alege Column, Line, Pie, Bar, Area, XY (Scatter), Stock, Surface, Radar, Combo
  4. Aplicare stil rapid:
    • Design → Chart Styles (galerie cu stiluri predefinite)
    • Design → Quick Layout (layouts cu/fără legendă, titluri, gridlines)
  5. Link către Excel extern:
    • Dacă ai diagramă în Excel, copiază-o (Ctrl+C)
    • În Word → Paste Special → Paste Link
    • Diagrama rămâne legată de fișierul Excel - se actualizează când modifici Excel-ul

📉 Subiect 9: Tipuri de diagrame și formatare

Alegerea și personalizarea diagramelor

📚 Noțiuni teoretice:

Tipuri de diagrame și utilizări:

Column/Bar - pentru comparații între categorii. Line - pentru tendințe în timp. Pie - pentru proporții din total (procente). Area - pentru volume cumulate în timp. Scatter (XY) - pentru corelații între variabile.

Elemente unei diagrame: Chart Title (titlul), Axes (axe X și Y), Legend (legenda cu serii), Data Labels (etichete cu valori), Gridlines (linii grilă pentru citire).

Diagramele în Word sunt integrate cu Excel - datele se introduc într-o fereastră Excel mini care se actualizează automat în diagramă.

Pași pentru lucrul cu diagrame:

  1. Inserare diagramă:
    • Insert → Chart
    • Alegeți tipul: Column, Line, Pie, Bar, Area, XY (Scatter), Stock, Surface, Radar, etc.
    • Click OK - se deschide fereastra Excel pentru date
  2. Introducere date:
    • În fereastra Excel, introduceți datele
    • Coloanele = serii de date
    • Rândurile = categorii
    • Diagrama se actualizează automat
    • Închideți Excel când terminați
  3. Modificare tip diagramă:
    • Selectați diagrama
    • Design → Change Chart Type
    • Alegeți noul tip și stil
  4. Formatare diagramă:
    • Design → Chart Styles pentru stiluri rapide
    • Design → Quick Layout pentru aranjamente
    • Design → Chart Elements (+) pentru: Title, Legend, Data Labels, Gridlines, Axes
    • Format → Shape Fill/Outline pentru culori personalizate
  5. Elemente diagramă:
    • Chart Title - titlul diagramei
    • Axis Titles - titluri axe
    • Legend - legenda
    • Data Labels - etichete valori
    • Gridlines - linii grilă
    • Click pe element → Format pentru personalizare
  6. Editare date:
    • Click pe diagramă
    • Design → Edit Data
    • Se redeschide fereastra Excel
